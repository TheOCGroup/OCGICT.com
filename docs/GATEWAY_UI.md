# OCGICT Gateway UI Direction

The public experience is intentionally built around four visible pillars:

1. Cinematic Wichita identity and architecture.
2. Persistent conversational G gateway on every public page.
3. Seller path: address -> a few guided questions -> private intelligence -> guarded preliminary offer -> accept/counter/walkthrough.
4. Investor path: acquisition, renovation strategy, investment analysis, and consulting.

G is the public-facing AI orchestrator. HUNTER, VICTOR, and PIPER remain specialized operational agents behind the experience.

Production must not present synthetic parcel records, comps, ARV, renovation numbers, or offers as real results.
